# RustDesk 一鍵安裝：使用說明

## 檔案內容
| 檔案 | 用途 |
|---|---|
| `一鍵安裝RustDesk.bat` | **按兩下這個**就會開始安裝 |
| `install_rustdesk.ps1` | 安裝主程式，`.bat` 會呼叫它。**兩個檔案要放在同一個資料夾** |

## 使用步驟（每台電腦約 3 分鐘）
1. 把整個資料夾複製到隨身碟或該電腦的桌面。
2. 對 `一鍵安裝RustDesk.bat` 按兩下。
   - 出現「Windows 已保護您的電腦」時，按「其他資訊」→「仍要執行」。
   - 出現「是否允許此 App 變更您的裝置」時，按「是」。
3. 依畫面提示操作：
   - 【密碼】輸入固定密碼（8 碼以上，不可有空白或雙引號），輸入時畫面不會顯示字元，這是正常的。
   - 【用途】1 = 一般文書電腦，2 = 試驗設備電腦（關閉檔案傳輸與剪貼簿）。
   - 【電源】被連線的電腦建議選 Y（插電時永不睡眠）。
4. 完成後畫面會顯示這台電腦的 **RustDesk ID**，同一個資料夾也會產生「RustDesk安裝紀錄_電腦名稱_日期.txt」。

## 自動完成的項目
- 從 RustDesk 官方 GitHub 下載最新版，並核對檔案的 SHA256 與數位簽章
- 靜默安裝，建立桌面捷徑，設成開機自動啟動
- 設定固定密碼（密碼**不會**寫進安裝紀錄）
- 試驗設備電腦：關閉檔案傳輸與剪貼簿，可選擇是否需要現場人員按「接受」
- 設定插電時不睡眠
- 產生安裝紀錄（可列印簽名，歸檔作為品質紀錄）

## 注意事項
- 電腦需要能連上網路，並使用有系統管理員權限的帳號。
- 已經裝過 RustDesk 的電腦會跳過下載與安裝，只做後面的設定。
- 安裝紀錄裡的 ID 請登記在公司的設備或帳號清冊。密碼請另外登記在密碼清冊。
